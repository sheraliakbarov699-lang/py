# venv, virtualenv va Poetry — solishtirish jadvali

| Xususiyat | venv | virtualenv | Poetry |
|---|---|---|---|
| O'rnatish | Python 3.3+ bilan birga keladi | pip orqali alohida o'rnatiladi | Alohida installer yoki pip orqali |
| Tezlik | O'rtacha | venv'ga nisbatan biroz tezroq | Muhit yaratish sekinroq (dependency hisoblanadi) |
| Python 2 support | Yo'q | Bor | Yo'q |
| Dependency boshqaruvi | Yo'q, faqat pip freeze | Yo'q, faqat pip | Bor — pyproject.toml va poetry.lock |
| Paket nashr qilish | Yo'q | Yo'q | To'liq qo'llab-quvvatlaydi |
| Qachon qo'l keladi | Kichik-o'rta loyihalar | Eski Python versiyasi bilan ishlash | Katta jamoaviy loyihalar |
